# API DB Extract (ETL Pipeline)

This is a Python-based ETL pipeline designed to extract blacklist/sanction data from various sources (Inaproc and World Bank) and load it into a centralized database (Erica API).

## Setup Instructions

1. **Create and activate a virtual environment:**
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```

2. **Install dependencies:**
   ```bash
   uv sync
   ```

3. **Configure the Environment variables:**
   Copy the example environment file and fill in your credentials.
   ```bash
   cp .env.example .env
   ```
   Open `.env` and fill out your `TARGET_API_BASE_URL`, `TARGET_API_ACCOUNT_UID`, `TARGET_API_DATASET_UID_*`, and `TARGET_API_TOKEN`.

## Usage

Current `src.main` runs both sources (`inaproc` and `worldbank`) in one execution and sends data to the configured Erica datasets.

```bash
uv run python -m src.main
```

There is no CLI `--source`, `--mode`, or `--dry-run` in the current implementation.

## Output & Logs

Pipeline output is written to the application logs (stdout), including:
- per-source extraction progress
- insert status to Target API
- Inaproc dedupe summary (`before`, `after`, `removed_duplicates`)

No checkpoint/dead-letter/report files are generated by the current `main.py` flow.
